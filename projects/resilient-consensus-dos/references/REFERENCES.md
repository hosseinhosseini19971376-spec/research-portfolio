# References

## Primary reference

Z. Zuo, X. Cao, Y. Wang, and W. Zhang, “Resilient Consensus of Multiagent Systems Against Denial-of-Service Attacks,” *IEEE Transactions on Systems, Man, and Cybernetics: Systems*, vol. 52, no. 4, pp. 2664–2675.

DOI: [10.1109/TSMC.2021.3051730](https://doi.org/10.1109/TSMC.2021.3051730)

The paper studies consensus of multi-agent systems under DoS attacks that block information exchange. Its abstract describes a distributed observer-based controller for reconstructing agent states, constraints on attack frequency and duration, and a case where both controller and observer communication networks are jammed.

This repository contains Simulink model files and project documentation, not the publisher's PDF. The supplied models implement selected parts of the paper's observer-based framework; see the project README and Model Guide for implementation limits.
